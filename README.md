## ⚡ What is Zalgo Text?
Zalgo text (commonly referred to as cursed, demonic, void, or glitch text) is created by appending an excessive number of combining characters (Unicode diacritics) above, below, and across standard alphanumeric letters. This creates a vertical text distortion effect that overflows standard line height.
